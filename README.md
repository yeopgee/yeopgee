## Selected Projects

The following projects were completed through KUBIG (Korea University Data Science & AI Society). 
Each link leads to a repository containing my contributions and a link to the team's work.

**[Beyond CNN: Feature-map shifts](https://github.com/yeopgee/beyond-cnn-shift-operators)** · Fall 2025
- **Team:** Explored ways to widen CNN spatial context without attention or large convolution kernels.
- **My contribution:** Implemented feature-map shifts and evaluated their effects on effective receptive fields and classification accuracy.

**[Dog age transformation](https://github.com/yeopgee/dog-age-conditional-gan)** · Fall 2025
- **Team:** Investigated age-conditioned image generation for dogs, motivated by missing-dog searches.
- **My contribution:** Led the project and implemented conditional GAN variants and an image-reconstruction procedure.

**[Two-way Korean Sign Language translation](https://github.com/yeopgee/sign-language-keypoint-translation)** · Spring 2025
- **Team:** Developed a system for translating between Korean Sign Language and Korean text.
- **My contribution:** Built the keypoint-to-text pipeline with a BiGRU encoder and attention-based decoder.

**[DACON fraudulent listing detection](https://github.com/yeopgee/dacon-fraudulent-listings)** · Spring 2025
- **Team:** Explored models for identifying fraudulent real estate listings from tabular data.
- **My contribution:** Engineered listing and agency-risk features and tuned an XGBoost classifier.
