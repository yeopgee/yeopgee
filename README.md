# Jiyeop Kim

M.S. student in Mathematical Statistics at Korea University. I work on statistical learning and sufficient dimension reduction, with a broader interest in how the structure of data can guide reliable and efficient learning methods.

## Research

My master's research develops sparse dimension reduction methods for multimodal data with block missingness. I am especially interested in statistical methodology, computation, and the role of geometric or multimodal structure in learning.

## Selected projects

| Project | My contribution |
| --- | --- |
| [Feature-map shifts for CNNs](https://github.com/yeopgee/beyond-cnn-shift-operators) | Implemented deterministic, random, and learnable shift operators and evaluated their effect on receptive fields and classification. |
| [Keypoint-based Korean Sign Language translation](https://github.com/yeopgee/sign-language-keypoint-translation) | Worked on keypoint preprocessing and a BiGRU encoder with an attention-based decoder for sign-to-text translation. |
| [Dog age transformation with a conditional GAN](https://github.com/yeopgee/dog-age-conditional-gan) | Led an age-conditional image generation project and explored reconstruction using pixelwise and perceptual losses. |
| [DACON fraudulent listing classification](https://github.com/yeopgee/dacon-fraudulent-listings) | Explored missingness and agency risk features, then tuned an XGBoost classifier for tabular listing data. |

These were collaborative projects. Each repository describes my role and provides the relevant code without datasets or trained model files.
